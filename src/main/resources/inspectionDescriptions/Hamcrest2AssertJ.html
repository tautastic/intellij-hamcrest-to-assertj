Reports Hamcrest assertThat() calls that can be rewritten as the equivalent AssertJ assertion.

Example:


assertThat("wrong size", list, hasSize(2));

After the quick fix is applied:


Assertions.assertThat(list).as("wrong size").hasSize(2);

The optional failure message is kept as an AssertJ description (as(...)) and the import for org.assertj.core.api.Assertions is added when needed.

Supported matchers:

  • equalTo, is (including true, false and null values)
  • nullValue, notNullValue
  • hasSize, empty
  • contains (converted to containsExactly), hasItem, hasItems
  • containsString, containsStringIgnoringCase
  • allOf, anyOf (converted to satisfies and satisfiesAnyOf)

Calls that use other matchers, or that pass a matcher where a plain value is expected (for example hasSize(greaterThan(2))), are not reported because they cannot be converted faithfully.
